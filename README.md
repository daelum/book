# THE 12-MONTH BODYBUILDER

Practical beginner-to-intermediate body-transformation guide structured around a clear **12-month roadmap**.

**GitHub home:** https://github.com/daelum/book  
**Working title:** THE 12-MONTH BODYBUILDER

## Manuscript layout

This repo is the **canonical manuscript home**. Project Context mirrors live under the agent store (`book/`, `docs/manuscript-status.md`).

```
book/
  outline/          Complete book outline (parts, chapters, pathways)
  chapters/         Chapter drafts (Markdown)
  maps/             Internal chapter↔source maps (not reader-facing)
docs/
  manuscript-status.md   Drafting status, research gaps, sync notes
README.md           This file
```

### Chapter file naming

```
book/chapters/ch-NN-slug.md
```

Example: `book/chapters/ch-01-what-bodybuilding-involves.md`

IDs match the outline in `book/outline/00-complete-outline.md`.

### Standard chapter scaffold

Most chapters use:

1. WHAT YOU NEED TO KNOW  
2. WHY IT MATTERS  
3. WHAT EXPERIENCED BODYBUILDERS DO  
4. YOUR ACTION PLAN  
5. YOUR TARGETS  
6. COMMON MISTAKES  
7. YOUR CHECKLIST  
8. WHAT’S NEXT

## Writing rules (short)

- Gym-mate voice: direct, practical, slightly irreverent — not textbook, not motivation poster.
- **Never** name YouTube creators, channels, or handles in manuscript prose. Provenance stays in research tooling only.
- **Never** invent Daelum biography; do not name Dylan or build coaching funnels in chapters.
- Beginner pathways stay **drug-free** in action plans. PEDs / peptides / GLP-1s are educational literacy only (Part Four).
- Mark unresolved evidence needs as `[RESEARCH: …]` in `docs/manuscript-status.md` only — not in reader chapter prose.
