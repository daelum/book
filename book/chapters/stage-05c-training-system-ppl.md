# Stage 5C — STRIPLINE Programmes: PPL & PPLU

This is the training chapter you run, not the one you skim for vibes.

Stage 5 already told you the rules: progressive overload, hard-enough sets, log the work, protect recovery. This chapter installs the **default STRIPLINE programmes** — the templates you put on the calendar tomorrow morning.

**Default recommendation (non-negotiable clarity):**

| Your reality | Default programme | Weekly shape |
|--------------|-------------------|--------------|
| You can train **6 days** and recover (sleep mostly OK, stress manageable) | **PPL** — Push / Pull / Legs | PPL → rest or light day → PPL → rest |
| You can train **4 days** hard, or 6 days feels like fantasy | **PPLU** — Push / Pull / Legs / Upper | Four training days; three rest or step days |
| Life will not allow 4+ days this season | **3-day full body** (fallback) | Mon / Wed / Fri or any three non-adjacent days |

Not “3–4 days vaguely.” Pick one. Lock it for 8–12 weeks. Stop inventing a new split every Sunday night.

PPL and PPLU are the primary STRIPLINE programmes because they hit each major muscle roughly **twice per week**, keep sessions themed and short enough to finish, and scale from beginner to intermediate without rewriting the skeleton. The 3-day full-body plan is the honest backup when schedule or recovery says no.

If you still want someone else watching the logbook and calling the shots, that’s fine later — [PLACEHOLDER: paid offer / coach funnel — pending agreement]. For now: write the days, lift the weights, eat for the phase.

### What “default” means here

These templates are **evidence-aware defaults**: each major muscle hit about twice weekly when you run PPL or the Push+Upper pairing in PPLU; compounds first; accessories that actually progress; effort near failure without living in form collapse; progressive overload you can measure. They are not a secret private coach sheet photocopied into a book. Where an exact coached prescription would matter and we don’t have clearance to invent one, you’ll see a sparse placeholder — not a fake protocol dressed up as gospel.

Year one does not require novelty. It requires attendance, hard sets, and a logbook that proves next week was a little better than last week.

## How to choose: PPL vs PPLU vs 3-day

### Choose **PPL** when

- You can guard **six training days** most weeks (construction, shift work, kids — if you’ve got the slots, use them).
- Sessions can be **45–70 minutes**.
- Sleep is mostly decent and you’re not already living in a deep deficit crash.
- You like theme days: push day feels like push day.

**Typical PPL week:**

| Day | Session |
|-----|---------|
| Mon | Push |
| Tue | Pull |
| Wed | Legs |
| Thu | Rest or long walk |
| Fri | Push |
| Sat | Pull |
| Sun | Legs |

That’s two full PPL cycles. Each muscle gets hit twice. Rest Thursday (or move the rest wherever life needs it). Don’t skip Legs twice and call it “prioritising upper.”

### Choose **PPLU** when

- **Four hard days** is what you’ll actually hit.
- Six days sounds heroic and you already know you’ll ghost Fridays.
- You’re in a hard STRIP deficit and six hard sessions leave you flat.
- You’re newer and want slightly more recovery between hard lower-body days while still covering upper twice.

**Typical PPLU week:**

| Day | Session |
|-----|---------|
| Mon | Push |
| Tue | Pull |
| Wed | Rest / steps |
| Thu | Legs |
| Fri | Upper |
| Sat | Rest / steps |
| Sun | Rest or optional easy walk |

Push + Upper covers chest/shoulders/triceps twice. Pull covers back/bis. Legs once hard — and Upper still includes some rear-delt / upper-back work so the week doesn’t feel half-empty. If you want legs twice on a four-day plan later, you can swap Upper for a second lower day — but **PPLU as written is the default four-day STRIPLINE template**.

### Choose **3-day full body** when

- You cannot protect four days.
- You’re restarting after a long layoff and need practice without burying yourself.
- Travel, overtime, or childcare makes PPL/PPLU a lie this month.

Three hard full-body days beat six skipped half-sessions. Run it without shame. Upgrade when the calendar allows.

### Recovery check (be honest)

If joints ache, sleep is wrecked, and every session is junk for two weeks straight — you don’t need a fancier split. You need fewer hard sets, more food or sleep, or a MED week (below). Programme choice sits under recovery, not above it.

### Real-life schedule examples (steal one)

**Early shift / construction-style days:** train after work three nights + weekend mornings for PPLU; or early AM short sessions for PPL if you’ve got the discipline and sleep isn’t toast. If 4 a.m. wake-ups already exist, don’t add hero PPL on five hours of sleep — pick PPLU.

**Office / hybrid:** Push Mon lunch, Pull Tue after work, Legs Thu morning, Upper Sat. Rest Wed/Fri/Sun. That’s a clean PPLU.

**Kids / evenings only:** three weeknights + one weekend day. If a weeknight dies, the weekend becomes the make-up — not a free pass to skip the pattern.

**Shift work:** map the split to your **waking days**, not the calendar’s Mon–Sun ego. Two Push / two Pull / two Legs across your work cycle for PPL; or four quality sessions across the roster for PPLU. Consistency of stimulus beats matching Instagram’s week.

**Travel month:** run 3-day full body with hotel DBs / bands, or MED Push/Pull/Legs in 30–40 minutes. Resume the locked template when you land — don’t “try a new split I saw.”

### Switching between PPL and PPLU mid-block

Allowed when life actually changes — not when you’re bored.

- **Downgrade PPL → PPLU** if you miss two+ sessions per week for two weeks, or recovery collapses.
- **Upgrade PPLU → PPL** only after 4+ weeks of hitting all four days, sleep is fine, and you want more frequency — not because a mate trains six days.
- Keep as many **exercise selections** as you can when you switch so the logbook still means something.

## Session structure (every training day)

Same skeleton for PPL, PPLU, and full body.

### 1. Warm-up (8–12 minutes)

- 3–5 minutes easy cardio or brisk walk into the gym.
- Dynamic bits for the day’s joints (arm circles, hip openers, bodyweight squats — don’t invent a yoga class).
- **Ramp sets** on the first compound: empty bar / light machine → add load → one last light–moderate set. Ramp sets are not work sets. Don’t count them as volume.

### 2. Work sets

- Hit the listed **sets × reps**.
- Most working sets: about **1–2 reps in reserve (RIR)** — near failure, form still honest.
- Last hard set of an isolation can flirt with 0–1 RIR if the joint feels fine.
- Stop a set when form collapses into ego theatre. That rep didn’t count anyway.

**RPE quick map (use one language in the logbook):**

| Feel | RIR | RPE (approx.) |
|------|-----|---------------|
| Could do 3+ more clean reps | 3+ | ≤7 |
| Could do ~2 more | 2 | ~8 |
| Could do ~1 more | 1 | ~9 |
| No clean reps left | 0 | 10 |

Target most compounds at **RPE 8–9** once you’ve learned the movement. Week 1 beginners: leave a little more in the tank while you find the groove — still not polite gym tourism.

### 3. Rest times

| Lift type | Rest |
|-----------|------|
| Heavy compounds (squat, hinge, press, row) | **2–3 minutes** (up to 3–4 if truly heavy) |
| Machines / secondary compounds | **90–150 seconds** |
| Isolations (curls, laterals, pushdowns) | **60–90 seconds** |

Rest is part of the programme. Scrolling for four minutes between lateral raises is not “intensity.”

### 4. Logging (non-optional)

Every session, write:

- Exercise
- Load
- Sets × reps actually done
- Rough RIR / RPE on the hard sets
- One-line note if something hurt or sleep was rubbish

Phone notes app, notebook, spreadsheet — pick one. If it’s not logged, you didn’t progress; you exercised.

### 5. Finish

You’re done when the list is done. No bonus burnout circuit unless the template says so. Save energy for the next session.

### Finding week-1 loads (so you can train tomorrow)

You do not need a one-rep max calculator. You need a starting number that lets you learn the movement and still work hard by the end of the week.

1. **Guess light.** First working set should feel like you could do the top of the rep range easily.
2. **Adjust set to set.** If set 1 was 12 reps with four left in the tank on an 8–12 lift, bump the load for set 2. If set 1 died at 5 reps with ugly form, strip weight.
3. **Lock a load for next time.** By the end of session one, you should know “this is my working weight for bench right now.” Write it down.
4. **Week 1 bias:** leave ~2–3 RIR while grooves form. Weeks 2–3: push most sets to ~1–2 RIR.
5. **Machines vs free weights:** machines often let you push closer to failure sooner because the path is fixed — still don’t bounce into joint pain.

If you are returning after months off, start more conservatively than your old PRs. Pride is not a warm-up set.

### What to bring / how to use the gym floor

- Water, headphones optional, **logbook mandatory**.
- Claim a rack or bench for the main lift; do accessories that don’t steal someone else’s compound station for forty minutes of laterals.
- If a machine is taken, do the **next free exercise in the same pattern**, then return — don’t stand still for ten minutes protecting a seat with a towel and a glare.
- Train the planned day even if the gym is busy. Busy is not a programme change.

## Effort and form cues (coach voice, not textbook)

**Chest presses:** shoulder blades set, wrists stacked, lower with control, drive without bouncing the bar off your ribs like a trampoline.

**Overhead work:** ribs down, don’t turn every press into a standing crunch. If your lower back is doing the lift, the load is too heavy or the setup is lazy.

**Rows / pull-downs:** pull elbows, not just hands. Pause a beat at the squeeze. Don’t cheat every rep into a hip-hinge Olympic event.

**Squats / leg press:** depth you own, knees tracking roughly over toes, no ego depth that turns into a lower-back story. Full range you control beats half-reps with a plate you can’t earn.

**Hinges (RDL / back extension):** soft knees, push hips back, feel hamstrings/glutes — not a rounded spine speed-run.

**Lateral raises:** slight elbow bend, lead with elbows, stop before shrugging the weight to your ears.

**Curls / extensions:** own the negative. Swinging the torso for the last three “reps” is cardio with a dumbbell.

**Effort rule:** if you finish every set knowing you had four clean reps left, you didn’t train — you visited. If every set ends in a screaming form dump, you didn’t train — you performed. Live in the middle: hard, clean, progressive.

**Breathing (simple):** brace before the hard part of the rep — don’t hold a purple face for a twelve-rep set. Exhale through the sticking point on presses and squats; stay braced enough that your spine doesn’t become a garden hose.

**Tempo default:** controlled down (roughly 2 seconds), crisp up. No need for fancy 4010 codes. If you bounce every rep, slow the eccentric until you own it.

**Pain vs effort:** muscle burn and the urge to quit near the end of a hard set is normal. Sharp joint stabbing, unusual nerve zings, or pain that alters your gait walking out of the gym is not “the programme working.” Deload that pattern, swap the variation, get it checked if it persists.

**Film one set per week** of your hardest compound. Watch it once. Fix one thing. That’s coaching without a coach.

## Progressive overload: double progression

This is the engine. The split is just the calendar.

**Rule (default):**

1. Pick a **rep range** (usually **8–12** for most hypertrophy work; **6–10** on some heavier compounds if you prefer).
2. Use a load you can hit the **bottom** of the range for all prescribed sets at ~1–2 RIR.
3. When you hit the **top** of the range for **all** work sets with solid form, **add load** next session (smallest plate jump that makes sense — often 2.5 kg total on dumbbells/machines, 2.5–5 kg on barbells).
4. New load will often drop you back toward the bottom of the range. Climb again.

### Example — dumbbell bench, 3×8–12

| Session | Load | Result | Next move |
|---------|------|--------|-----------|
| Week 1 Mon | 22.5 kg | 12, 11, 10 | Keep load; push reps |
| Week 1 Fri | 22.5 kg | 12, 12, 11 | Keep load |
| Week 2 Mon | 22.5 kg | 12, 12, 12 | **Add load** |
| Week 2 Fri | 25 kg | 10, 9, 8 | Build reps again |

That’s progress. Not a new exercise every week because Instagram was bored.

### When you stall for 2–3 sessions on a lift

1. Check sleep, protein, and whether you’re actually near failure.
2. Keep the load; earn the reps.
3. If still stuck: small form fix, longer rest, or swap to a close variation (e.g. DB press → machine press) and progress that.
4. Do **not** add five random sets of junk.

### Accessories

Same double-progression logic. Smaller jumps. Ego laterals with trapezius shrugs don’t count as shoulder growth.

### Example — leg press, 3×6–10

| Session | Load | Result | Next move |
|---------|------|--------|-----------|
| Week 1 Legs A | 120 kg | 10, 9, 8 | Keep; push reps |
| Week 1 Legs B (PPL) | 120 kg | 10, 10, 9 | Keep |
| Week 2 Legs A | 120 kg | 10, 10, 10 | **Add 5–10 kg** |
| Week 2 Legs B | 130 kg | 8, 7, 6 | Build back up |

If the machine stack jumps are huge, hit the top of the range, then add a slow eccentric or a 1-second pause before you chase the next plate.

### What counts as overload (and what doesn’t)

**Counts:** more load at same reps; more reps at same load inside the range; same load/reps with cleaner deeper range you previously shortened; controlled pauses that make the set harder *on purpose* when plates don’t exist.

**Doesn’t count:** longer sessions with gossip between sets; random drop sets every week that aren’t logged; swapping the whole lift because last session felt hard; “I sweated more.”

## Default PPL templates (complete)

Use gym versions first. Home swaps are later in this chapter. Rest between sets as above. Target ~1–2 RIR on work sets unless noted.

**Weekly volume philosophy:** this is a **solid beginner–early intermediate default**, not a pro prep sheet. If you’re crushed after week two, cut one accessory set per day before quitting the split. If everything feels easy and you’re recovering well by week six, add **one** set to a lagging movement — not seven.

[PLACEHOLDER: coach-specific detail] — if you later run a coached template, keep the same split logic; swap exercise brands/machines to what your coach programmes. Don’t invent secret protocols from the internet and call them “the system.”

### Push day (chest, shoulders, triceps)

| Order | Exercise | Sets × reps | Notes |
|-------|----------|-------------|-------|
| 1 | Barbell or dumbbell bench press | 3 × 6–10 | Main horizontal press. Ramp first. |
| 2 | Seated dumbbell shoulder press **or** machine shoulder press | 3 × 8–12 | Controlled; no back arch circus. |
| 3 | Incline dumbbell press **or** incline machine press | 3 × 8–12 | Upper chest bias; stop short of flaring into pain. |
| 4 | Cable or dumbbell lateral raise | 3 × 10–15 | Strict. Rest-pause last set only if form holds. |
| 5 | Triceps pushdown (cable) **or** overhead triceps extension | 3 × 10–15 | Full range; elbows quiet. |
| 6 | Optional: pec deck **or** cable fly | 2 × 12–15 | Only if recovered; skip on MED weeks. |

**Time:** ~50–65 minutes.  
**Finishers:** none required.

### Pull day (back, rear delts, biceps)

| Order | Exercise | Sets × reps | Notes |
|-------|----------|-------------|-------|
| 1 | Chest-supported row **or** seated cable row | 3 × 6–10 | Squeeze mid-back; don’t bounce. |
| 2 | Lat pull-down **or** assisted pull-up | 3 × 6–10 | Full stretch up top; pull elbows down. |
| 3 | One-arm dumbbell row **or** machine row | 3 × 8–12 /side | Brace; no rotating the whole room. |
| 4 | Straight-arm cable pulldown **or** dumbbell pullover | 2–3 × 10–15 | Lats lengthened; light enough to feel. |
| 5 | Rear-delt fly (cable/machine/DB) | 3 × 12–15 | Soft elbows; don’t turn into a row. |
| 6 | EZ-bar or dumbbell curl | 3 × 8–12 | Own the negative. |
| 7 | Optional: face pull | 2 × 12–15 | Light, crisp; great if shoulders feel beat-up. |

**Time:** ~50–70 minutes.

### Legs day (quads, glutes, hamstrings, calves)

| Order | Exercise | Sets × reps | Notes |
|-------|----------|-------------|-------|
| 1 | Back squat **or** goblet squat **or** leg press | 3 × 6–10 | Choose the pattern you can load safely. |
| 2 | Romanian deadlift (barbell or DB) **or** seated/lying leg curl | 3 × 8–12 | Hinge with pride; keep lumbar honest. |
| 3 | Walking lunge **or** Bulgarian split squat **or** leg press (if squat was free-weight) | 3 × 8–12 /side | Controlled; knee tracks. |
| 4 | Leg extension | 2–3 × 10–15 | Squeeze at the top; don’t slam. |
| 5 | Standing or seated calf raise | 3 × 10–15 | Pause at the bottom stretch. |
| 6 | Optional: back extension or cable crunch | 2 × 10–15 | Core/posterior; not a twenty-minute ab class. |

**Time:** ~55–75 minutes. Eat something with carbs around this day if you train hard in a deficit — legs punish empty tanks.

### PPL micro-notes

- Swap bilateral for machines if you’re learning or your lower back is noisy — tension still counts.
- Keep **exercise order** unless a machine is taken; then swap within the same slot, don’t delete the pattern.
- If Pull takes forever because the cable station is a social club, start with the row that is free and circle back.
- Missed Wednesday Legs? Do Legs Thursday and shift the rest day — don’t “skip Legs and do arms instead.”
- Two Pushes in a row because you skipped Pull is not clever. Make up the missed *theme*.
- Optional fly / face-pull / core lines: use them when recovered; drop them first when life gets loud.

### Example PPL week 1 (concrete)

| Day | What you do |
|-----|-------------|
| Mon Push | Warm-up → bench find loads → finish table → log → steps if behind |
| Tue Pull | Warm-up → rows/pull-downs → arms → log |
| Wed Legs | Carbs somewhere near the session if dieting → squat/hinge/lunge → calves → log |
| Thu | Rest or long walk; protein still hits |
| Fri Push | Same lifts as Mon; try to beat Mon’s reps or match with cleaner form |
| Sat Pull | Same idea vs Tuesday |
| Sun Legs | Same idea vs Wednesday; if crushed, MED Legs and go home proud |

That’s a beginner-runnable week. No seminar required.

## Alternative: 3-day full-body template

For people who **cannot** run PPL or PPLU this season. Three non-consecutive days. Same RIR, rest, and double progression.

| Order | Exercise | Sets × reps |

| 1 | Squat or leg press | 3 × 6–10 |

| 4 | RDL or leg curl | 2–3 × 8–12 |
| 5 | Lateral raise | 2 × 12–15 |
| 6 | Curl or triceps (alternate each Day A) | 2 × 10–15 |

### Day B

| Order | Exercise | Sets × reps |
|-------|----------|-------------|
| 1 | Hex-bar deadlift, trap-bar, or leg press hinge bias **or** goblet squat if recovery is thin | 3 × 5–8 |
| 2 | Overhead press (DB/machine) | 3 × 6–10 |
| 3 | Lat pull-down or assisted pull-up | 3 × 6–10 |
| 4 | Walking lunge or split squat | 2–3 × 8–12 /side |
| 5 | Rear-delt fly | 2 × 12–15 |
| 6 | Triceps or curl (opposite of last Day A choice) | 2 × 10–15 |
| 7 | Calf raise | 2–3 × 10–15 |

| Order | Exercise | Sets × reps |
|-------|----------|-------------|
| 1 | Leg press or squat variation | 3 × 8–12 |
| 2 | Incline press | 3 × 8–12 |
| 3 | Single-arm row | 3 × 8–12 /side |

## STRIP vs LIFT: same skeleton, different bias

The programme days do **not** magically change when you move from fat-loss-first to growth emphasis. The **food and recovery bias** does.

| Lever | STRIP (fat-loss emphasis) | LIFT (growth emphasis, when earned) |
|-------|---------------------------|-------------------------------------|
| Calories | Deficit (see Stage 5 nutrition) | Small surplus or high maintenance |
| Protein | High end of the band | Still high — surplus carbs aren’t a protein substitute |
| Session template | **Same PPL / PPLU / 3-day** | **Same** |
| Effort on key lifts | Keep intensity; protect compounds | Keep progressing; add volume carefully if recovering |
| Volume | Prefer trimming accessories before gutting main lifts | Room to add a set where progression stalls |
| Steps / cardio | Often higher to help the deficit | Don’t erase the surplus with punishment cardio |
| Deloads | Still scheduled — deficits fatigue you | Still scheduled — surplus isn’t immortality |
| Bad weeks | MED sessions (below) | MED sessions — life doesn’t care about your phase name |

**Rule:** do not rewrite the whole programme because you started eating more. Progress the lifts. Adjust the plate. That’s STRIPLINE.

Skinny-fat and higher-body-fat readers: stay in STRIP bias longer than your impatience wants. Hardgainers with a documented lean starting point: you may earn LIFT calories sooner — still run the same training skeleton.

## Home vs gym swaps (key lifts)

Progressive overload still wins. Bands and dumbbells work if the reps get harder over time (more load, harder band, slower eccentrics, extra set only when earned).

| Gym lift | Home / limited-kit swap |
|----------|-------------------------|
| Barbell bench | DB floor press, push-up variations (elevate feet / weight vest / pause), resistance-band press |
| Incline press | DB incline on adjustable bench or floor with hips elevated; band incline press |
| Overhead press | DB seated press; band press; pike push-up progression |
| Cable lateral raise | DB laterals; band laterals |
| Triceps pushdown | DB overhead extension; band pushdown on door anchor; close-grip push-up |
| Cable / chest-supported row | Single-arm DB row; backpack/backpack-loaded row; band row |
| Lat pull-down | Band pulldown; inverted row under table; towel row |
| Pull-up | Band-assisted if you have a bar; otherwise inverted rows + pulldown bands |
| Back squat | Goblet squat; DB squat; backpack squat; split squat emphasis |
| Leg press | Goblet squat + split squat pairing; heel-elevated DB squat |
| RDL | DB RDL; single-leg DB RDL; band hinge |
| Leg curl | Sliding leg curl on towel/socks; band curl |
| Leg extension | DB Spanish squat / heel-elevated goblet focus for quads; sissy-squat regression only if knees happy |
| Calf raise | Single-leg calf raise on a step with backpack |
| Pec deck / fly | DB floor fly (careful shoulders); band fly |
| Face pull | Band face pull; prone Y/T raises |

**Home programming tip:** when load jumps are awkward, use **double progression on reps first**, then add a slow 3-second eccentric, then add a set only if recovery is clear. Don’t chase gym-only exercises while your adjustable dumbbells gather dust.

## Deload rules

Plan the deload so you don’t invent one after an injury.

**Default:** every **6–8 weeks** of hard training, or earlier if sleep tanks, joints complain, and performance slides for ~7–10 days despite honest effort.

**Deload week options (pick one):**

1. **Same exercises, ~50–70% usual load, same or slightly fewer sets, stop at ~3–4 RIR.**  
2. **Keep load moderate, cut sets roughly in half.**  
3. **MED week** (below) if life is chaos — still counts as training, not failure.

Deload is not “seven days of couch and guilt.” Walk. Sleep. Eat protein. Come back hungry to train — not wrecked.

**Do not** deload every time the scale is noisy. Deload for **fatigue and performance**, not for feelings after one bad session.

## Bad-week MED sessions (minimum effective dose)

When overtime, sick kids, or a mental cliff shows up: **do not rewrite the programme at 11 p.m.** Run MED versions. You’re still on STRIPLINE.

| Exercise | Sets × reps |
|----------|-------------|
| Bench press variation | 2–3 × 6–10 |
| Shoulder press variation | 2 × 8–12 |
| Lateral raise | 2 × 12–15 |
| Triceps pushdown/extension | 2 × 10–15 |

### MED Pull

| Exercise | Sets × reps |
|----------|-------------|
| Row | 3 × 6–10 |
| Lat pull-down / pull-up regression | 2–3 × 6–10 |
| Rear-delt fly or face pull | 2 × 12–15 |
| Curl | 2 × 8–12 |

### MED Legs

| Exercise | Sets × reps |
|----------|-------------|
| Squat or leg press | 2–3 × 6–10 |
| RDL or leg curl | 2 × 8–12 |
| Lunge or split squat | 2 × /side 8–12 |
| Calf raise | 2 × 10–15 |

**Rules:** ~40 minutes max. Still ~1–2 RIR on the compounds. Log it. Resume full template next week. Missing the week entirely trains the wrong habit.

On **PPLU**, MED Upper = bench or incline + row + laterals + one arm movement (2 sets each).

On **3-day**, MED day = squat/press/row pattern, 2 sets each, go home.

### When to use MED vs full deload vs skip

| Situation | Move |
|-----------|------|
| Busy week, body fine | MED sessions; keep the days |
| Performance sliding ~7–10 days, sleep poor | Planned deload week |
| Acute illness / fever | Skip hard training; walk if able; resume MED then full |
| One rough night’s sleep | Train full unless unsafe; maybe leave an extra RIR |
| Motivation dip only | Show up; often the first compound fixes the mood |

Skipping “because I deserve rest” every time life is mildly annoying is how six-day PPL becomes zero-day regret.

## Steps, cardio, and the lifting week

STRIP loves steps. Lifting still owns the calendar.

- **Default:** get steps on rest days and after sessions if needed — walking is not a substitute for Pull day.
- **Cardio:** 1–2 easy Zone-2 style sessions (20–30 minutes) is plenty for most year-one lifters if steps are already solid. Put them on rest days or after upper sessions, not before heavy Legs when it nukes your squat.
- **Hard conditioning every day** plus six-day PPL plus a deep deficit is how people stall, sleep badly, and blame genetics.
- **Hardgainers in LIFT:** watch that cardio doesn’t quietly erase the surplus. Lift hard, walk some, eat.

Steps targets live in Stage 5’s playbook. Here the rule is simpler: **never cancel a programmed Lift day to “do more cardio instead”** unless a coach or clinician has a specific reason. Fat loss is mostly the food deficit plus consistency; the programme builds the muscle you’re trying to keep.

## Running an 8–12 week block (don’t freestyle)

1. **Weeks 1–2:** learn loads, grooves, calendar. Effort climbing toward 1–2 RIR.
2. **Weeks 3–6:** double progression in full swing. Same exercises. Log everything.
3. **Week 7 (or 6–8):** deload if fatigue is real — or keep rolling if you feel strong *and* performance is still climbing. Don’t deload from boredom.
4. **Weeks 8–12:** resume hard training. Add at most one set to a lagging lift if recovery is clearly fine. Optional small exercise swap only if a joint hates a movement — same pattern, new tool.
5. **End of block:** photos, waist, strength notes. Decide: stay on the same split another block, or switch PPL ↔ PPLU for life reasons — not vibes.

## Troubleshooting (quick fixes)

| Problem | Likely fix |
|---------|------------|
| Sessions run past 90 minutes | Cut optionals; watch rest on isolations; stop phone-scrolling |
| Shoulders angry on bench | Try DB or machine; control depth; add face pulls; check overhead volume |
| Lower back angry on RDL | Soften knees; shorten range; swap to leg curl for a block |
| No pump / “don’t feel it” | Slow eccentric; full stretch; actually approach failure — feeling isn’t the only scoreboard |
| Strength dropping in STRIP | Expected some weeks; protect protein/sleep; keep intensity; trim accessories before compounds |
| Only chest growing | Stop skipping Pull and Legs; row as hard as you press |
| Can’t do Pull after Push (sore) | Normal early on; keep showing up; soreness fades with consistency |
| Hate Legs | Do them anyway; machines are legal; physique is not upper-body only |
| Partner / mate wants a different split | Run *your* locked template; joint sessions can share a gym, not a random programme |
