# Appendix — Year Logbook & Tracker

Print these pages. Write on them. Bring them back for twelve months.

This is the **follow-along paper system** for *The 12-Month Body*. Use it with Stage 5A’s month plan, Stage 5B’s nutrition workflow, and Stage 5C’s PPL/PPLU templates. Digital apps (Cronometer / Hevy defaults) are fine — still paste weekly averages here so the year stays visible on paper.

**How to use:** fill **Food Bro targets** once → run **weekly templates** (photocopy or duplicate in Notes) → complete **twelve monthly overviews** → do **quarterly reviews** → keep PPL session sheets in the gym bag.

## STRIPLINE phase checklist (revisit monthly)

### STRIP
- [ ] Calories in deficit (or recomp that still improves midsection)
- [ ] Protein hit most days
- [ ] PPL/PPLU sessions still progressive
- [ ] Steps floor active
- [ ] Photos show midsection moving **or** lean exception documented

### LINE
- [ ] One programme locked (no hopping)
- [ ] Food targets written
- [ ] Sleep + step floors written
- [ ] Review date on calendar

### LIFT (only when criteria met)
- [ ] STRIP→LIFT checklist passed (Stage 5A)
- [ ] Calories at maintenance/surplus as planned
- [ ] Same split; volume added conservatively
- [ ] Not using “bulk” to avoid hunger honesty

### LINK
- [ ] Human check-in happened this week/month
- [ ] I told the truth about adherence
- [ ] Placeholder coaching door noted if needed: `[PLACEHOLDER: paid offer / coach funnel — pending agreement]`
